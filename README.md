# logicbyte.ai

The website of [Logic Byte](https://logicbyte.ai) — AI-powered image analytics.

## What this is

A static site: plain HTML, CSS and JavaScript, with no framework and no build step. Open any page in a browser to preview it.

- `index.html` — home
- `platform.html` — the OptiFlow platform
- `biomedical.html`, `semiconductor.html`, `custom.html` — the three verticals
- `research.html`, `research-output.html` — research and the full record
- `about.html`, `contact.html`, `card.html` — company, contact form, founder card
- `vercel.json` — redirects and headers

## Deployment

Deployed by Vercel from `main`. A push to `main` goes to production.
